Performance

The KV cache grows with context size × parallel slots; quantizing it can let a model fit on fewer GPUs.
Flash attention: faster attention and less memory where the GPU supports it; a quantized KV cache needs it. Micro-batch: tokens of a prompt read per pass. Bigger reads long prompts faster on GPUs with tensor cores (Volta, cc 7.0 and newer), costs compute memory on every GPU, and does not change generation speed.
A quantized KV cache needs flash attention: set it to Auto or On.
Only for GGUFs that ship multi-token-prediction (nextn) layers, such as Qwen3.5, GLM-4.5 and newer, DeepSeek V3. No extra file; the server refuses models without them.

Fewer passes of the big model per token. Helps most when the model is split across servers (fewer network round trips). Measured on one small GPU: n-gram +11 %, a 0.5B draft with 4 tokens +5 %, 8 tokens slower.
